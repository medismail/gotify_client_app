# Gotify Windows icon assets

`gotify-logo-notification-96.png` is the official Gotify notification icon from
[`gotify/logo`](https://github.com/gotify/logo/blob/master/gotify-logo-notification-96.png).
The Gotify logo is licensed under the
[Creative Commons Attribution 4.0 International License](https://creativecommons.org/licenses/by/4.0/).

The notification icon was drawn by Choi Wong and optimized by Pander Musubi;
all rights are owned by the Gotify organization, as documented in the upstream
[`gotify/logo` README](https://github.com/gotify/logo/blob/master/README.md).

`gotify.ico` is generated from that official notification mark. The mark is
placed on Gotify's `#3f51b5` application theme color and packaged at several
Windows icon sizes for the executable and system tray.
